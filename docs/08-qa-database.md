# عضو 8 — الجودة والداتابيز والتسليم (QA + DB + Docs)

## 1. مهمتك ايه بالظبط
ضمان ان كل حاجة شغالة: الداتابيز، الداتا التجريبية، اختبار الـ 54 شرط، ملفات التشغيل، GitHub، والعرض. انت خط الدفاع الأخير قبل المناقشة.

## 2. المفاهيم اللي لازم تعرف تشرحها
- PostgreSQL داتابيز حقيقية للشغل الجد (علاقات + قيود unique + transactions)، وSQLite للتجربة السريعة.
- الـ seed يعني سكريبت بيملا داتا تجريبية بأمر واحد (idempotent: لو اتنفذ مرتين مبيضاعفش).
- الـ acceptance test يعني قايمة بكل الشروط المطلوبة وبتتجرب واحدة واحدة (احنا وصلنا 58/58).
- الـ .gitignore يعني ملفات مبتترفعش (الباسورد والبيئة والصور المرفوعة).

## 3. الملفات بتاعتك سطر بسطر
### الداتابيز
- سطبنا PostgresPro 17 كسيرفس على بورت 5432، وعملنا داتابيز `ecommerce_db` ويوزر `postgres`.
- الاتصال من `.env` (مش من الكود) عشان كل جهاز يظبط بياناته.

### أوامر الداتا (catalog/management/commands/)
- `seed`: 4 كاتيجوري + 10 منتجات ديمو (get_or_create فآمن للتكرار).
- `seed_real`: بيجيب 150 منتج حقيقي بصورهم من DummyJSON API بمكتبة urllib القياسية بس، والأسعار بتتحول دولار لجنيه ×48.
- `seed_deals`: بيحط 45 منتج على خصومات 10 ل 50% بنفس التوزيعة كل مرة.

### الاختبار
- اتعمل سكريبت فحص بيجرب كل شرط من الـ 54 برقم (تسجيل غلط، ايميل مكرر، تجاوز مخزون، أوردر حد تاني...) والنتيجة كانت 58/58.
- أهم bugs اتمسكت: سباق التسجيل المكرر (500 → رسالة لطيفة)، وتشابه slug منتجين (حل برقم تلقائي).

### التشغيل والتسليم
- `setup.bat`: أي جهاز جديد بيدوس دابل كليك — venv + مكتبات + migrate + داتا + سيرفر (واتجرب على نسخة نظيفة).
- `SETUP.md`: شرح عربي للمستلم، و`README.md`: توثيق إنجليزي للريبو.
- GitHub: الريبو Public، والـ commits بأسماء أصحابها، والأسرار بره الجيت.

## 4. انت مربوط بمين
- بالكل: بتجرب شغل عضو 2 ل 7، وبتسلم شغل عضو 1 (setup) للي هيستلم المشروع.

## 5. أسئلة مناقشة متوقعة
- س: إزاي اتأكدتوا ان الـ 54 شرط شغالين؟ ج: سكريبت acceptance بيجربهم برقم والنتيجة 58/58، ولسه محتفظين بمنهجية التجربة.
- س: الداتا الحقيقية جت منين؟ ج: من DummyJSON API بأمر seed_real، والصور hotlinked من CDN بتاعهم.
- س: لو الباسورد بتاع الداتابيز اتسرب؟ ج: هو أصلا في .env اللي مش مرفوع، وكل جهاز ليه ملفه.
- س: حد جديد ينضم للفريق يعمل ايه؟ ج: clone ثم دابل كليك setup.bat — اتجربت من الصفر.

## 6. العرض اللايف بتاعك (دقيقتين)
1. نفذ `python manage.py seed_deals` وورّي العروض اتجددت.
2. افتح GitHub وورّي الـ commits والـ README.
3. احكي bug واحد اتمسك ازاي (التسجيل المكرر) — دي أكتر حاجة بتعجب المناقشين.
