## 1. مهمتك ايه بالظبط
السلة كاملة: إضافة + كمية + زيادة ونقصان + مسح عنصر + تفريغ + المجاميع — وكل ده من غير جدول في الداتابيز. ملفاتك: cart/cart.py (الكلاس) و cart/views.py و cart/urls.py.

## 2. من الصفر خالص: يعني ايه اللي انت عملته
- الـ session يعني درج خاص بكل زائر على السيرفر. السيرفر بيعرف الزائر من cookie في المتصفح وبيفتح له الدرج بتاعه.
- اخترنا session مش داتابيز لسبب بسيط: الزائر المجهول (مش مسجل دخول) ملوش صف في الداتابيز نخزن عليه، فالدرج المؤقت هو الحل.
- السلة عندنا قاموس بسيط جدا: رقم المنتج هو المفتاح والكمية هي القيمة. مثال: `{'7': 2}` معناها منتج رقم 7 بكمية 2.
- `session.modified = True` سطر إجباري: Django مبيحفظش التعديل على القاموس إلا لو قلت له انه اتعدل.

## 3. قاموس المصطلحات بتاعتك
- session: مخزن مؤقت لكل زائر (default بيعيش أسبوعين).
- dict: قاموس (مفتاح وقيمة).
- yield: زي return بس بترجع حاجة حاجة من غير ما تخلص الدالة (للذكاء في اللوب).
- subtotal: مجموع الصنف الواحد (سعره × كميته).
- stock guard: حارس المخزون اللي بيمنع أي كمية فوق المتاح.

## 4. الكود سطر بسطر
### البداية (الكونستراكتور)
```
def __init__(self, request):
    self.session = request.session
    cart = self.session.get('cart')
    if cart is None:
        cart = self.session['cart'] = {}
    self.cart = cart
```
- أول مرة الزائر ييجي بنعمل له درج فاضي. بعد كده بنفتح درجه الموجود.

### الإضافة (الشروط 32 و 33 و 40)
```
def add(self, product, qty=1):
    new_qty = self.cart.get(pid, 0) + int(qty)
    if new_qty > product.stock:
        return False
    self.cart[pid] = new_qty
    self.save()
    return True
```
- بيجيب الكمية القديمة ويزود عليها الجديدة. لو المجموع فوق المخزون بيرفض ويرجع False، والـ view بتحوله لرسالة بعدد المتاح.
